【软件简介】
NS 是一款 Windows 开发环境扫描与管理工具。以管理员权限运行，
可快速扫描本机中的编程开发环境，按计算机语言分类、程序名称首字母排序罗列，并支持定位目录、
访问官网、启动官方卸载等管理操作。

【运行要求】
  - Windows 10 / 11（需 .NET Framework 4.x，系统自带）
  - 绿色单文件：解压即用，无需安装
  - 首次运行弹出用户账户控制（UAC），点“是”即可

【快速开始】
  1. 双击 NS.exe 启动
  2. 点击“扫描环境”，约 1～2 秒完成
  3. 结果按“语言分类 + 程序首字母排序”罗列，可搜索过滤

【页面说明】
  ● 环境概览
    - 扫描环境：只读扫描 注册表 / PATH / 磁盘常用安装目录
    - 搜索框：按名称、语言、版本、安装路径、识别来源过滤
    - 管理所选（按钮或右键菜单）：
        · 在资源管理器中显示 —— 打开安装目录
        · 访问官方网站 —— 浏览器直达官网
        · 启动官方卸载 —— 调用软件登记的官方卸载程序（需确认）
  ● 下载中心
    - 按语言分类列出各开发环境的官方网站 / 下载页
    - “访问官网”按钮直达；NS 不提供、不托管任何安装包
  ● 关于
    - 产品信息与数据说明

【快捷键】
    F5       重新扫描
    Ctrl+F   聚焦搜索框

【界面语言】
    自动跟随 Windows 系统语言：简体中文系统显示中文，
    其他语言系统显示英文。

【数据与安全】
  - 扫描为只读操作，不修改注册表、PATH 或环境变量
  - 卸载仅启动软件官方卸载程序，NS 不直接删除文件
  - 所有信息仅在本机处理，不上传、不联网收集
